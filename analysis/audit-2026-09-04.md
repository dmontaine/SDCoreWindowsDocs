part of any document set and does not ship. It exists so that a correction can
be checked without repeating the measurement, and so that a claim that was

## Settled during the audit

**q7, the `limitssh` question, closes as superseded rather than answered.**
Two different checkboxes were being conflated. The task that wrote
`AllowGroups` and `ForceCommand` into `sshd_config` stopped being a task on the
owner's ruling of 21 Aug 2026 and is now unconditional; the machine the
question worried about — one carrying an ssh server somebody else configured —
no longer reaches the wizard, because `ssh-preflight.ps1` refuses the install
from `InitializeSetup`. Owner, 4 Sep 2026: *"We require the removal of any ssh
server prior to the initial install of SD. So the config is ours."*

**Installing the OpenSSH server is optional, and the documentation must say
so.** PRE_RELEASE 67, ruled 30 Aug 2026, closed 2 Sep. The `sshserver` task is
`checkablealone unchecked`; a full install with both boxes blank leaves
`OpenSSH.Server` at `STATE=NotPresent`. Three states are reachable — no server,
server without remote access, server with remote access — and API-only is a
supported deployment.
