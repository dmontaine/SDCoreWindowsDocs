# syntax-shapes.txt - the syntax of every name whose shape an argument count
# cannot express.  One "NAME = markdown" per line; mksyntax.py fills the rest
# in from BCOMP's dispatch table and REFUSES to write the card if anything is
# left over on either side.
#
# *italics* = you supply it.  `backticks` = typed as it stands.  {braces} =
# optional.  Taken from documents 01 to 17, where these were measured, and
# from BCOMP's statement compilers where no page covers them.
